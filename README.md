# Products API (Express + TypeScript + MySQL2)

1. `npm install` (incluye express-validator)
2. Ejecutar `database.sql` en MySQL.
3. `cp .env.example .env` y completar credenciales.
4. `npm run dev` (desarrollo) · `npm run build` · `npm start`

Importar `products-api.postman_collection.json` en Postman y ejecutar las
solicitudes en orden (la #3 guarda el id creado en `{{id}}`).
